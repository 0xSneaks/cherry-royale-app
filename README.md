# Cherry Royale — Android shell

Capacitor shell for the Cherry Royale web app (Cherry Slots, play credits only).
Loads https://cherry-royale-cherry.vercel.app in a native Android WebView shell.

CI builds an unsigned release APK and attaches it to the `fdroid-v1` release;
the APK is signed locally for distribution through the Cherry Royale F-Droid repo.
